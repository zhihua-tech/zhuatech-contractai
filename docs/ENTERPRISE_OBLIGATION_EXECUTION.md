# 企业合同义务履约与续约监控

Copyright © 2026 上海如静知华信息科技有限公司 · <https://www.zhuatech.cn/>

`POST /api/enterprise/contractai/obligation-execution` 把合同审查后的付款、交付、报告、合规和续约义务转换为可执行台账。接口逐项计算到期天数、逾期暴露金额、证据完整性和例外审批状态，同时检查交易对手、制裁筛查、法务保全和自动续约通知期。

系统返回 `ON_TRACK / ACTION_REQUIRED / LEGAL_ESCALATION / BLOCKED`。重大义务逾期或错过续约通知期会升级法务；完成但无证据、七日内到期以及未批准的豁免会生成待办；制裁命中或法务保全会阻断自动处置。

生产环境可将模型抽取的候选义务映射为本接口的结构化输入，但合同责任人仍需确认义务、责任人和日期。模型建议不能绕过交易对手、证据、续约和法务门禁。
